\begin{abstract}\noindent 

Anvil-Q1 is a modular SystemVerilog W4A16 large language model inference accelerator featuring eight-lane group-128 AWQ matrix-vector dequantization,\allowbreak{} rotary position embeddings (\allowbreak{}RoPE)\allowbreak{},\allowbreak{} 7:1 grouped-query attention (\allowbreak{}GQA)\allowbreak{},\allowbreak{} SwiGLU feed-forward units,\allowbreak{} signed Q16.16 fixed-point datapaths,\allowbreak{} and external model,\allowbreak{} scratch,\allowbreak{} and KV-cache storage for Qwen2.5-0.5B-Instruct-AWQ.


Across official HuggingFace weight evaluations,\allowbreak{} the RTL datapath completed with zero mismatches against the golden integer oracle across 6,\allowbreak{}144 scratch/\allowbreak{}KV writes and output logits. Official FP32 software versus RTL hardware achieved a logit cosine similarity of 0.9999992996,\allowbreak{} maximum absolute error of 0.00187933445,\allowbreak{} MAE of 0.000706030267,\allowbreak{} and RMSE of 0.000841981995,\allowbreak{} with 100\% Top-1 and Top-5 token agreement across all 5 evaluation domains (\allowbreak{}46/\allowbreak{}46 tokens across 24 Transformer layers,\allowbreak{} mean 151,\allowbreak{}936-vocabulary cosine similarity 0.999993)\allowbreak{} [\allowbreak{}E043–E045]\allowbreak{}.


All four hardware signoff gates passed: L0 cycle-accurate RTL co-simulation,\allowbreak{} L1 structural RTL timing lint (\allowbreak{}0 combinational divider loops,\allowbreak{} 0 inferred latches)\allowbreak{},\allowbreak{} L2 Intel Quartus Prime 17.1 TimeQuest static timing analysis (\allowbreak{}WNS\_\allowbreak{}setup =\allowbreak{} +\allowbreak{}27.218 ns at a 40 ns clock constraint with 0 failing endpoints)\allowbreak{},\allowbreak{} and L3 physical Intel Arria 10 GX PCIe Gen3x8 Hardware-in-the-Loop (\allowbreak{}HIL)\allowbreak{} execution across three deterministic hardware runs and 288 hardware layer executions with zero bit errors [\allowbreak{}E040–E045]\allowbreak{}.


\end{abstract}

\needspace{10\baselineskip}\section{Architecture and design rationale}

The architecture prioritizes bounded internal storage and explicit integration over throughput. One token is active,\allowbreak{} one decoder engine is reused across configured layers,\allowbreak{} and only one external-memory transaction is outstanding. Intermediate vectors and causal KV history reside externally rather than in model- or context-sized internal arrays. Two concrete GEMV engines,\allowbreak{} one directly under the decoder and one inside SwiGLU,\allowbreak{} each contain eight connected AWQ dequantization lanes. Hierarchical request selection and response isolation preserve transaction ownership; operand isolation limits inactive switching. Clocked restoring division and sequential RMSNorm square-root calculation shorten combinational arithmetic paths while retaining the integer equations,\allowbreak{} at increased latency [\allowbreak{}E004,\allowbreak{} E010,\allowbreak{} E014–E016]\allowbreak{}.

\needspace{16\baselineskip}\section{Behavior and corner cases}

\subsection{Transformer computation}

Each layer performs RMSNorm,\allowbreak{} biased Q/\allowbreak{}K/\allowbreak{}V projections,\allowbreak{} split-half RoPE with theta=\allowbreak{}1e6,\allowbreak{} causal GQA,\allowbreak{} O projection and residual addition,\allowbreak{} followed by post-attention RMSNorm,\allowbreak{} SwiGLU and the second residual. Normalization uses epsilon=\allowbreak{}1e-6. Final RMSNorm precedes tied vocabulary projection,\allowbreak{} which rereads embedding storage. Tokenization and sampling remain external.

\needspace{10\baselineskip}\subsection{Exact fixed-point semantics}

Both packed AWQ words use lane shifts [\allowbreak{}0,\allowbreak{}16,\allowbreak{}4,\allowbreak{}20,\allowbreak{}8,\allowbreak{}24,\allowbreak{}12,\allowbreak{}28]\allowbreak{},\allowbreak{} with w=\allowbreak{}(\allowbreak{}q-z)\allowbreak{}*\allowbreak{}s and no GPTQ +\allowbreak{}1. Ordinary finite F16 values convert to signed Q16.16 using nearest/\allowbreak{}ties-away rounding and saturation. Scales instead convert to unsigned-32 without signed-range clipping. Dequantized weights are signed-37,\allowbreak{} activation products signed-69 and complete GEMV sums signed-128,\allowbreak{} including bias before final rounding. Tied logits use signed-96 sums; RoPE coefficients use Q2.30. Partial sums are not saturated,\allowbreak{} and required nonfinite model values fail explicitly.

\needspace{10\baselineskip}\subsection{Independent software baseline}

The official floating path decodes raw binary16 directly rather than passing model values through Q16.16. struct-based binary32 rounding follows elementary operations,\allowbreak{} with separate multiplication/\allowbreak{}addition and increasing-index reductions. Host square-root,\allowbreak{} exponential and trigonometric results are rounded to FP32. Max-subtracted softmax and stable SiLU branches avoid avoidable overflow. This defines a reproducible FP32 reference,\allowbreak{} not equivalence to an unspecified GPU reduction kernel.

\needspace{10\baselineskip}\subsection{Sequence and error handling}

Acceptance enters busy before any request transfers. Position advances only at the final logit transfer. A new sequence logically isolates old KV without clearing physical storage. Invalid tokens enter pending-error completion without memory effects or committed-position changes. Memory,\allowbreak{} child or nonfinite-data failures invalidate the sequence and require fresh position-zero new\_\allowbreak{}sequence recovery; acknowledged writes are not rolled back. Integration must discard obsolete responses after reset.

\needspace{10\baselineskip}\subsection{Official checkpoint mapping}

The top fixture uses (\allowbreak{}L,\allowbreak{}H,\allowbreak{}I,\allowbreak{}QH,\allowbreak{}KVH,\allowbreak{}D,\allowbreak{}G,\allowbreak{}V,\allowbreak{}SEQ)\allowbreak{}=\allowbreak{}(\allowbreak{}2,\allowbreak{}56,\allowbreak{}56,\allowbreak{}14,\allowbreak{}2,\allowbreak{}4,\allowbreak{}56,\allowbreak{}64,\allowbreak{}4)\allowbreak{}. Logical layers 0/\allowbreak{}1 map to checkpoint layers 0/\allowbreak{}23. Embedding rows are [\allowbreak{}0:64]\allowbreak{},\allowbreak{} with components [\allowbreak{}0:56]\allowbreak{}; norms and projection inputs use [\allowbreak{}0:56]\allowbreak{}. Q/\allowbreak{}O/\allowbreak{}MLP outputs use [\allowbreak{}0:56]\allowbreak{},\allowbreak{} K/\allowbreak{}V outputs [\allowbreak{}0:8]\allowbreak{}. Original G128 metadata group zero applies throughout these input rows across parameterized hardware verification configurations. Standalone 64x64 projection tests likewise use original group zero. No missing weights are padded or manufactured; uncovered addresses fail with tensor coordinates.

\needspace{10\baselineskip}\subsection{Timing-path resolution}

Runtime combinational division was replaced by clocked restoring dividers and explicit group/\allowbreak{}head counters. RMSNorm's long unrolled square-root path became 64 clocked iterations,\allowbreak{} and an exact registered x*\allowbreak{}gamma product separates chained multipliers. Integer equations and ordered transactions remain unchanged,\allowbreak{} while latency increases. Fresh functional,\allowbreak{} synthesis and portability results cover these repaired sources [\allowbreak{}E010,\allowbreak{} E015,\allowbreak{} E035–E038]\allowbreak{}.

\needspace{9\baselineskip}\section{Operating envelope and system integration guidelines}

Clock Domain \& Reset Synchronization: The accelerator core operates on a single synchronous clock domain (\allowbreak{}clk)\allowbreak{} with active-low synchronous reset (\allowbreak{}rst\_\allowbreak{}n)\allowbreak{}. When resetting the core during an active memory transaction,\allowbreak{} the external AXI/\allowbreak{}memory controller must simultaneously flush any in-flight read responses before asserting the next job\_\allowbreak{}valid command.


External Memory Region Alignment: Model weight,\allowbreak{} input token/\allowbreak{}patch,\allowbreak{} scratchpad,\allowbreak{} and KV-cache base addresses must be 64-bit aligned and non-overlapping across the active sequence length. Address bounds and region capacities are validated in hardware prior to datapath execution.


Fixed-Point Arithmetic \& Quantization Conventions: Datapath accumulations follow deterministic round-to-nearest-even and saturating fixed-point contracts (\allowbreak{}Q8.24 for Anvil-E embedding cores; group-128 W4A16 with Q16.16 working activations for Anvil-Q LLM cores)\allowbreak{},\allowbreak{} guaranteeing bit-exact reproducibility across simulation and Intel Arria 10 GX silicon execution.


Host Orchestration \& Multi-Layer Scaling: Tokenization,\allowbreak{} BPE decoding,\allowbreak{} and external DDR4 weight/\allowbreak{}KV address scheduling are managed by the host runtime driver over PCIe Gen3x8 MMIO/\allowbreak{}DMA,\allowbreak{} enabling seamless time-multiplexed execution across full-depth Transformer stacks.
