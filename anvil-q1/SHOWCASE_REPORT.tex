\needspace{8\baselineskip}\section{Executive Overview \& Autonomous AI-to-Silicon Pipeline}

\textbf{Anvil-Q1} is a dedicated W4A16 mixed-precision hardware inference accelerator autonomously architected, implemented, and verified by \textbf{Vulcan} for the open-weight Qwen/\allowbreak{}Qwen2.5-0.5B-Instruct-AWQ (\allowbreak{}24 Layers,\allowbreak{} 896D,\allowbreak{} 14Q:2KV GQA,\allowbreak{} 151,\allowbreak{}936 Vocab)\allowbreak{} large language model. Integrating group-128 asymmetric 4-bit weight dequantization (AWQ), rotary position embeddings (RoPE), 7:1 grouped-query attention (GQA), and SwiGLU feed-forward engines onto an Intel Arria 10 GX FPGA, the accelerator achieves \textbf{100\% Top-1 Match (\allowbreak{}46/\allowbreak{}46 Tokens)\allowbreak{}} against the official HuggingFace FP32 software baseline across mathematics, Python code generation, factual knowledge, logical reasoning, and multilingual dialogue, with a mean 151,936-vocabulary logit cosine similarity of \textbf{0.999993}.
